# 双语版使用与改动说明

## 用法

1. 解压 Windows 包，运行 `Y2A-Auto.exe`，在设置页配置现有 AI 翻译服务。
2. 英语视频使用英语源字幕，经 AI 翻译成中文后，输出**英语在上、中文在下**的双语字幕；不直接把现有中文字幕当成英语源字幕。启用字幕翻译，再按需启用双语字幕；需要烧录时同时启用字幕嵌入视频。
3. 三个双语开关相互独立，默认均关闭：`SUBTITLE_BILINGUAL_ENABLED`（字幕）、`BILINGUAL_TITLE_ENABLED`（标题）、`BILINGUAL_DESCRIPTION_ENABLED`（简介）。标题/简介保留原文并组合译文，仍受平台长度限制。
4. 修改字幕模式后请**新建任务**验证。旧任务可能复用已下载、已翻译或已烧录的缓存；改变设置不会自动重做所有旧产物。

### CPA 地址（Windows）

AI 服务地址须填写 **Windows 能访问的 CPA OpenAI 兼容 API 地址**，通常以 `/v1` 结尾，端口按 CPA 的实际监听配置填写。CPA 在同一台 Windows 上时使用 `http://127.0.0.1:<CPA端口>/v1`；CPA 在另一台机器上时使用该机器的可访问 IP/域名，不要把另一台机器的 `127.0.0.1` 直接复制到 Windows。确认 CPA 的监听地址、防火墙及所选模型可用；API Key 只在本机设置中填写，不放入源码、说明或截图。本说明未固定用户私有服务的主机与端口。

## 投稿类型

设置项 `UPLOAD_COPYRIGHT_TYPE` 由 AcFun 与 bilibili **共享**：

- `repost`：转载，**默认值**；保留来源信息与转载说明。
- `original`：自制；按平台自制类型提交，不附转载来源与转载说明。
- 无效值回退为 `repost`，设置页保存路径已覆盖测试。

“自制”只改变提交字段，不证明拥有版权。给他人视频翻译、加字幕或重新剪辑，不自动获得原创/自制资格；请选择符合授权及平台规则的类型，版权风险由投稿者判断。

## 验证范围

- 用户已在 Windows 验收双语包，并反馈实际投稿成功。反馈未明确平台范围，不据此宣称两个平台均已实投验收。
- 定向离线回归覆盖字幕源选择、双语开关、VTT 字面内容/数字/多行/时间与静音间隔、严格翻译配对、真实 FFmpeg 烧录、标题简介组合、临时运行目录清理，以及两个平台的投稿类型字段和设置保存。
- 离线 AI/上传边界使用模拟；外部真实字幕样片只在本地存在时追加验证，未提交或打包。离线测试不等于完整应用、所有上游测试、所有视频或平台政策的全覆盖验收。

## Windows 构建与发布边界

`main` 与 `restart/bilingual` 推送均运行 **Windows build**，通过定向回归后复用上游打包器生成 Actions artifact，保留 14 天。下载入口：仓库 Actions → 对应提交的 Windows build → Artifacts（`Y2A-Auto-win64-preview-<提交SHA>`）。保留 preview 文件名仅为兼容现有下载习惯。

包检查禁止携带运行配置、cookies、数据库、日志、测试与审计样片。该构建仅生成 artifact，不创建 Release、不推 tag、不发布 Docker；原 Release/tag 发布触发器未改变，`restart/bilingual` 分支保留。
