# Y2A-Auto 1.0.1

基于 [fqscfqj/Y2A-Auto](https://github.com/fqscfqj/Y2A-Auto) 的自用 fork，遵循 GPL-3.0，非上游官方发行。

- 新配置默认 Roboto Medium，中文使用随包 Noto；已有字体配置及粗体默认不变。字体来源和许可见 `fonts/`。
- 双语标题使用 `中文 | 原文`，沿用平台标题限长。
- 双语简介保留完整原文、URL、重复链接、列表和空白；转载声明按实际元数据显示原视频、原作者、发布日期和视频链接，缺项省略。自制或关闭声明不追加来源，自定义翻译 prompt 不被覆盖。

简介含声明超过 AcFun 1000 / bilibili 2000 字时停止上传并提示编辑重试，不再静默截断。平台服务端仍可能有额外内容规则。
