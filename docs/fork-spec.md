# Y2A-Auto fork 行为规范

以 `release-1-1-5` 已交付行为为起点。本文件是 fork 有意区别于上游的**行为规范**；未列出的行为沿用上游。改行为时同步更新对应规范与验收；只替换实现时不改规范。上游实现满足同样验收时，优先采用上游，移除重复补丁。测试是验收证据，Git 和 Release 记录历史，不以代码偶然表现补写需求。

## SUB-1 字幕来源与双语输出

- 英语视频以匹配的英语字幕为源，优先选非自动轨，支持带语言变体后缀的轨道；仅在允许自动字幕时回退到匹配的自动轨。现成中文字幕或自动翻译轨不替代英语源文。
- 双语字幕英文在上、中文在下；保留源字幕的时间对应关系。对确认来自 YouTube 的滚动式自动字幕，在翻译前去掉重复滚动，把相邻两条新增字幕合成一屏；不把这套处理应用到非自动、非滚动或来源未确认的轨道。
- 对双语流程中新下载的 YouTube 非滚动式自动源字幕，仅在同轨原始事件能与已转换字幕逐条对应，且确认新事件替换同一显示窗口时，把上一条结束时间收至替换起点。保留不同窗口、追加显示、来源或对应关系不明的重叠；不绕过代理，不改人工、ASR、已有缓存或旧去滚动流程。
- 仅在双语 SRT 转 ASS 时移除 `b/i/u` 样式标签和有配对的 `font color`（单一颜色属性；允许标准颜色名及 3/6 位十六进制；不处理其他 HTML），并移除紧贴已识别标签的 U+200B 填充。保留原有明确空白位置的 `\h`／`\H` 清理；只在两个已识别样式标签之间将独立 `\N` 转为硬换行、`\n` 转为普通空格（当前 ASS 自动换行模式下的软换行效果）。不把未标明的路径、程序字面量或任意反斜杠当作字幕控制，也不清理其他零宽字符。
- 纯标记行不占字幕行，纯标记 cue 不显示。仅在双语烧录时，按同一条字幕的时间和完整原文确认上方英文块；普通英文源断行交给渲染器按实际可用宽度在词间折行，不按行尾词、下一行大小写或字数猜测，也不缩小字号。保留明确的说话人分隔、刻意换行、特殊格式及技术字面量；配对不可靠时保留原样。英文在上，中文在下，两种语言分别排版；不改中文排版、字体设置、时间轴、不同 cue、翻译、保存的字幕、同窗规则或单语路径。
- **烧录排版验收**：用留存真实字幕中旧规则不接受的普通短句，在相同字体、字号和画面尺寸下实测 FFmpeg/libass，核对英文由多行变一行、中文像素不变；将接受重新排版的条数与实际变成单行的条数分开记录。用自编长句、窄画面和双人对白验证按词折行和保留刻意断行；另核对含英文词的中文行、不可配对、时间、SRT 字节、标记清理和单语行为不变。[英文排版](../tests/test_bilingual_render_wrap.py)
- **验收**：用真实轨道结构和字幕样本验证选轨、重复去除、无内容丢失、双语行序及时间对应；非自动字幕样本不被改写。验证已确认的同窗替换在 libass 的交界帧不同时显示两条，且人工、多窗、追加、证据不完整及重复运行不会引入错误改写。用真实短 cue 和自编带标记样本核对 ASS 事件及 libass 帧：清理后的帧与手工参考一致，纯标记 cue 不产生像素；技术字面量、普通 HTML、字幕文件字节和单语行为不变。[选轨](../tests/test_youtube_manual_tracks.py) · [去滚动](../tests/test_auto_caption_derolling.py) · [双语](../tests/test_bilingual.py) · [烧录标记](../tests/test_bilingual_render_markers.py)

## SUB-2 无字幕与验收失败

- 确认没有可用源字幕（字幕元数据明确为空、没有字幕产物），且语音识别关闭时，跳过字幕处理，列表和详情持续显示「无字幕」，继续原流程。不新增确认或人工审核，不改变原自动投稿设置。没有字幕不等于没有对白。
- 有字幕轨但下载失败、文件损坏、译文不合格、烧录失败均不得当作正常无字幕放行。译文须与源条目和时间对应；允许部分翻译时只按既定规则放宽未译残留，不放宽结构校验。缓存译文也需验收；拒绝的产物不用于投稿。
- **验收**：正常处理和重试均可走无字幕分支，重开后提示仍在；启用语音识别或注入下载/字幕/翻译错误时，不误走此分支。[无字幕](../tests/test_no_source_subtitles.py) · [失败策略](../tests/test_subtitle_failure_policy.py) · [缓存与恢复](../tests/test_subtitle_upload_recovery.py)

## SUB-3 烧录与字体

- 上传准备和重试复用仍有效的烧录成品，不把已烧录成品作为再烧录的输入；确需重烧时使用原视频。
- 新配置及空白字体设置默认使用随仓库分发的 Noto Sans CJK SC Regular（`NotoSansCJKsc-Regular.otf`），西文与中文用同一字体。已有字体选择不自动迁移；显式选择 Roboto Medium 时保留原有中文回退。不改变字幕样式参数、时间或现有烧录成品。
- 内置 CPU libx264 烧录（含回退）没有累计时限。FFmpeg 启动或上次编码视频帧数创下新高后，连续 20 分钟没有新增编码帧才超时；重复或回退的帧数、音频进度和日志均不续期。运行中的这一 FFmpeg 阶段由无新帧超时监督，不因任务更新时间陈旧被自动回收提前中断；手动取消和自然退出不变。
- 其他编码阶段（包括自定义参数）保留原有单阶段和累计预算、负载估算和回退规则。分辨率、帧率、画质、编码预设及烧录失败后的原片回退不变。
- **验收**：重复上传准备不重复转码；FFmpeg/libass 对西文和中文均选中默认 Noto，显式选择 Roboto 时仍按旧方式渲染；持续出帧可越过旧上限，首帧缺失或停帧满 20 分钟才超时，手动取消和自然退出仍有效。核实在跑的内置 libx264 不被外围回收误杀，其他编码预算保持原样。[烧录复用](../tests/test_subtitle_burn_idempotency.py) · [字体](../tests/test_bundled_subtitle_fonts.py) · [无新帧超时](../tests/test_embed_active_timeout.py) · [预算估算](../tests/test_embed_4k60_timeout.py)

## DIST-1 构建与发布

- 本 fork 不再构建或发布 Windows 便携包，包括 Actions 预览产物与 Release 附件；不修改既有发布及附件。Linux CI 全量测试与 Docker 工作流保持独立。
- **验收**：工作流中没有 Windows 预览或发布构建，同时 Linux CI 仍运行全量测试。[工作流](../tests/test_workflows.py)

## META-1 标题、简介与投稿类型

- 字幕、标题和简介的三个双语开关独立，默认关闭。启用时，标题按 `中文 | English` 排列；简介中文在前、原文在后。保留原文和链接，超平台长度时优先保留启用的完整原视频信息，再截断正文，避免留下截断的 URL。
- AcFun 与 B 站支持转载（默认）或自制。自制不填平台的转载来源字段。可选的四行原视频信息（原视频、原作者、发布日期、视频链接）独立于投稿类型；不得编造缺失信息。
- **验收**：校验开关互不影响、正文及链接保留、平台长度边界，以及两种投稿类型各自启用/关闭原视频信息时的最终投稿字段。[双语](../tests/test_bilingual.py) · [简介长度](../tests/test_description_budget.py) · [投稿类型](../tests/test_upload_copyright_type.py)

## UP-1 B 站弱网重试与续传

- 海外线路 `txa`、`alia` 参与自动测速；选择依据实际探测，不强制使用海外线路。
- 分块传输按大小设置单次超时；暂态错误有界退避、可取消，遵守服务端要求的等待时间；永久错误不反复重试。
- 中断后，只有原会话仍可用、账号与成品匹配时，才跳过已经确认成功的分块继续上传。保存进度时保护会话凭据；会话不匹配或失效时明确停止，不静默从头重传。合并或投稿结果未知时，不自动重复提交。平台会话有效期不作承诺。
- **验收**：模拟暂态和永久错误以及取消；中断后用同一文件和会话重试，已确认块不重发、合并内容一致；账号或文件不匹配、结果未知时不得继续提交。[线路](../tests/test_bili_upload_lines.py) · [重试](../tests/test_bili_chunk_retry_policy.py) · [续传](../tests/test_upos_resume.py)
