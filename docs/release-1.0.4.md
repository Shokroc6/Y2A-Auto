# Y2A-Auto 1.0.4

- 字幕翻译默认严格验收；失败、缺源或损坏字幕停止两平台上传。修复成功后的诊断保留为历史，清除仅字幕错误状态；显式允许部分翻译的缓存遵循同一策略。真实写盘失败不再误报成功。
- 简介四行来源信息优先；Unicode/URL 安全截断，双语正文合理分配预算。
- 分块网络超时有界退避重试，证书错误不重试，不降低 TLS 校验；保留未知最终投稿结果的人工核查提示。
- 包含 1.0.3 的维护改动与上游 d5617ac7d97278fbd63fb77dfbe877cc63353dda 同步。
- Windows CI 增加字幕恢复及真实文件系统事务回滚沙箱。便携更新仅替换包内程序路径；所有配置、cookies、数据库、下载、AcFun ID、自定义字体、日志及其他非程序文件保留，备份不删除。不会自动启动应用或任务。

安装更新前关闭应用；使用 ZIP SHA256 与事务清单验证。PyInstaller 的静态页面与字体位于 `_internal`，无需复制成新的根目录。运行时 `ffmpeg`/`acfunid` 保持用户现状。网络证书/超时根因仍未完全确定，本版不承诺解决外部服务或本机信任链问题。
