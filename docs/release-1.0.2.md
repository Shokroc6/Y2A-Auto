# Y2A-Auto1.0.2

基于 [fqscfqj/Y2A-Auto](https://github.com/fqscfqj/Y2A-Auto) 的自用 fork，遵循 GPL-3.0，非上游官方发行。

- 修复 Windows 冻结包字体查找：从内置 `_internal/fonts` 查找 Roboto 和 Noto，不改变配置、数据库和日志目录。
- “追加原视频信息”开关独立于投稿类型：开启时自制和转载都按真实元数据追加四行，关闭时保留正文；自制仍不提交平台转载来源，转载类型和来源不变。

1.0.1 文档中的“自制不追加来源”只描述旧版行为；从本版起由开关独立控制简介信息。缺失元数据不生成，简介超限仍提示编辑后重试。此包没有新增上传诊断。Windows 构建与自动测试不等同桌面运行、真实投稿或用户验收；现有已就地修补安装无需重新下载。
